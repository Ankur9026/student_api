# Student API

A RESTful Student Management API built using Django REST Framework.

## 🚀 Features

- Django REST Framework
- Student CRUD API
- PostgreSQL Database
- Basic Authentication
- JSON API
- Postman API Testing

## 🛠️ Technologies Used

- Python
- Django
- Django REST Framework
- PostgreSQL
- Postman
- Git & GitHub
